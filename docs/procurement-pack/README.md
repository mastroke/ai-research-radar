## Related methodology

Cross-layer attribution follows the frozen-harness pattern described in
[mastroke/agent-loop-hillclimber](https://github.com/mastroke/agent-loop-hillclimber):
identical probes against Layer A (full agent) and Layer B (raw pinned API) so
acceptance evidence separates orchestration effects from model capability.
